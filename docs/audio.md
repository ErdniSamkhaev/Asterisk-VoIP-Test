# Аудио IVR и музыка ожидания

Три русских приглашения создаёт scripts/generate_ivr_prompts.py через eSpeak NG и SoX. Требуются python3, espeak-ng, sox. Итог: /var/lib/asterisk/sounds/custom/ivr-welcome.wav, ivr-invalid.wav, ivr-unavailable.wav; root:asterisk640, каталог 750. Проверка scripts/inspect_ivr_prompts.py подтверждает PCM mono8000Hz16bit, длительности 6.07/3.05/5.46 секунд на проверенном стенде. Голос синтетический; WAV можно заменить записанным диктором, сохранив имена и совместимый формат.

При переносе стенда генератор заменяет необходимость публиковать WAV. Он не перезаписывает существующие приглашения.

Музыка ожидания — стандартный набор Asterisk, уже установленный на VPS: moh show files вывел пять файлов в /var/lib/asterisk/moh. Эти сторонние музыкальные файлы не входят в репозиторий. На чистой машине обеспечить доступный набор музыки и класс в /etc/asterisk/musiconhold.conf, например:

```ini
[default]
mode=files
directory=/var/lib/asterisk/moh
```

В каталоге должны быть реально установленные читаемые аудиофайлы в поддерживаемом формате; один пример конфигурации музыку не создаёт. Проверить:

```bash
asterisk -rx "moh show classes"
asterisk -rx "moh show files"
```

Музыка и воспроизведение пользовательских приглашений на исходном стенде проверены реальными звонками. Исходные возможности новой сборки (format_wav, format_gsm и нужные кодеки) проверяются отдельно.
