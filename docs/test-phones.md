# Телефоны для проверки нескольких сотрудников

## Роли

| Клиент | Номер | Назначение |
| --- | --- | --- |
| Zoiper на ПК | 3000 | Вызывающий абонент |
| Zoiper на телефоне | 3400 | Первый сотрудник ТП; оставить приложение открытым на время теста |
| MicroSIP на ПК | 3401 | Второй сотрудник ТП |

MicroSIP предложен как отдельный клиент, чтобы одновременно сохранить вызывающего 3000 и два endpoint ТП. Пользователь подтвердил регистрацию 3401 в клиенте. CLI подтвердил контакты 3000, 3400 и 3401 Avail, а database show tp — 1793173579|3400,3401. Серия шести вызовов затем выбрала обоих сотрудников по три раза; все с ответом и bridge (evidence/tp-random-series.md). Затем эти клиенты можно переключить на номера КЦ для проверки распределения очереди.

## Подключение 3401

1. Пароль посмотреть локально на VPS: `sed -n '/^\[auth3401\]$/,/^$/p' /etc/asterisk/local/pjsip-auth-tp.conf`. Содержимое пароля не включать в доказательства и Git.
2. Скачать стабильную MicroSIP Lite (есть portable zip) с [официальной страницы](https://www.microsip.org/downloads). Распаковать, например, на рабочем столе в отдельную папку MicroSIP. Конфигурация клиента с паролями не входит в репозиторий проекта.
3. В Add Account задать SIP server `<VPS_IP>:5060`, Domain `<VPS_IP>`, Username и Login `3401`, пароль из локального auth, Transport UDP, Media encryption Disabled. Имя аккаунта можно указать TP 3401.
4. После регистрации проверить CLI контакты 3000, 3400 и 3401; затем AstDB с двумя ТП после очередного обновления таймера.

Подробности полей: [MicroSIP Documentation, Account и Account Settings](https://www.microsip.org/help#account).

## Проверка случайного выбора

После подтверждения двух регистраций вызвать 2001 с 3000 несколько раз, отвечая на выбранном телефоне и завершая каждый звонок до следующего. Сохранить строки TP selected; в серии должны наблюдаться оба номера. Это проверка выбора из актуального списка, а не доказательство статистической равномерности генератора. Реальный DID 74990000010 проверяется после подключения лабораторного транка.
