# Проверка локального комплекта

28.10.2026, Windows/Python3.13. Семь unittest тестов sync_tp_contacts прошли из корня итогового проекта: фильтрация/дедупликация, некорректный срок, полный списокAMIсActionID, неполный список, ошибкаAMI, разрыв соединения, недопустимые символы заголовка.

Также проверены синтаксис всех Python-скриптов без выполнения серверных генераторов, XML обоих SIPp-сценариев, bash -n для всех shell-скриптов, относительные Markdown-ссылки вне примеров кода. Реальных pjsip-auth-файлов, manager-tp.conf, ключей, сырых трасс/журналов и строк с32+hexсекретом в комплекте не обнаружено. Это проверки комплекта; функциональные результаты наVPSописаны отдельно в остальных evidence/.

Тесты не заменяют независимую установку на чистой машине, которая не проводилась. Публичная конфигурация сохранена отдельно от секретов, которые создаются наLinuxгенераторами.
