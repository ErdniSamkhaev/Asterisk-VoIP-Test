# Проверка загрузки аккаунтов техподдержки

После создания файлов ТП, инструкции добавить include и успешного reload res_pjsip.so пользователь выполнил проверки:

```text
asterisk -rx "pjsip show endpoints" | grep -E 'Endpoint:[[:space:]]+(3400|3499)/|Objects found:'
 Endpoint:  3400/3400  Unavailable  0 of inf
 Endpoint:  3499/3499  Unavailable  0 of inf
Objects found: 202
```

Начало вывода `asterisk -rx "pjsip show endpoint 3400"`:

```text
 Endpoint:  3400/3400  Unavailable  0 of inf
     InAuth:  auth3400/3400
        Aor:  3400  1
  Transport:  transport-udp  udp  0  0  0.0.0.0:5060
```

Подтверждены общий размер набора (202 endpoint), наличие крайних номеров ТП и ссылки на auth/AoR у 3400. Это согласуется с генерацией 100 аккаунтов ТП поверх прежних 102 endpoint. Данная выборочная проверка не является отдельной сверкой всех 100 идентификаторов. Контактов ТП пока нет; регистрация, звонок, внешний скрипт AstDB и случайный выбор ещё не проверены.

## Регистрация и прямой звонок на 3400

В следующей проверке пользователь выполнил pjsip show contacts и получил два контакта: 3000 Avail (217.317 ms) и 3400 Avail (210.249 ms), Objects found: 2. Затем вызвал 3400 с 3000 и подтвердил звук в обе стороны. Контакт 3300 в этом выводе отсутствует. Данные адресов и SIP contact URI здесь опущены.

Регистрация и прямой внутренний звонок 3400 подтверждены. Скрипт AstDB, случайный выбор и вызов через городской DID ещё не реализованы и не проверены.
