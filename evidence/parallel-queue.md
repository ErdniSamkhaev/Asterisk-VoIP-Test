# Два одновременных входящих вызова после перезапуска

28.10.2026, 10:48:47–10:49:24 UTC. Пользователь создал отдельный сценарий provider-uac-parallel.xml и запустил test_queue_headers_parallel.sh. Два входящих DID74990000000, разные X-Customer-ID через call_number; уникальные X-Lab-Trace предусмотрены сценарием.

SIPp: Total calls2, peak2 after2s, Successful2, Failed0. Два INVITE, два ACK, два BYE и два ответа200 на завершение; UDP errors0. Echo RTP2646 пакетов. Пользователь подтвердил эхо в обоих вызовах. Отдельное распределение RTP между двумя вызовами счётчик echo не доказывает.

После теста подтверждены PJSIP Logging disabled и Removed dynamic logger channel lab-headers-parallel.log. Полная трасса осталась на VPS: /var/log/asterisk/lab-headers-parallel.log; в Git не переносится.

Статус изоляции заголовков: проверен ниже по четырём INVITE и строкам Queue/answered. Этот тест подтверждает провайдерские вызовы после restart; повтор маршрута ТП после restart остаётся.
