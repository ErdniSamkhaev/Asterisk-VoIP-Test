# Проверка внутреннего разговора: F03

Стенд: Asterisk 22.11.0, PJSIP, клиенты 3000 и 3001. Предварительно оба клиента одновременно зарегистрированы с контактами Avail; см. pjsip-startup.md.

## Настройки RTP

Команда cat /etc/asterisk/rtp.conf подтвердила:

```ini
; RTP media port range for the test lab.
[general]
rtpstart=10000
rtpend=20000
strictrtp=yes
```

## Сценарий и результат

Предложенный сценарий: с клиента 3000 вызвать 3001, ответить, проверить разговор в обоих направлениях и завершение звонка. Пользователь сообщил: «все работает звонок держится больше 30 секунд и слышно в обе стороны».

F03 выполнен по ручной проверке. Это подтверждает внутренний разговор между двумя тестовыми клиентами в текущей сети. Остальные группы номеров, IVR, очередь и транк проверяются отдельными сценариями.

Маршрут использует Dial(PJSIP/${EXTEN},30). Параметр 30 ограничивает ожидание ответа; после ответа он не завершает разговор через 30 секунд.
