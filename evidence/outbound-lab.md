# Исходящий вызов в лабораторный транк

## Условия

Предложенный сценарий: с Zoiper 3000 набрать внешний тестовый номер 74991234567; Asterisk направляет его в lab-provider, SIPp UAS принимает один вызов на локальном порту 5062 и возвращает RTP через echo. Пользователь прислал итоговый экран запуска команды scripts/run_provider_uas.sh.

## Подтверждённый результат SIPp

| Показатель | Итог |
| --- | --- |
| Total Calls created | 1 |
| Successful call, cumulative | 1 |
| Failed call, cumulative | 0 |
| INVITE / ACK / BYE, received | по 1 |
| 180 / 200 INVITE / 200 BYE, sent | по 1 |
| Retrans / Timeout / Unexpected-Msg | 0 в показанном сценарии |
| RTP echo, первый поток | 1141 пакет |
| UDP errors send/recv/congestion | 0/0/0 |

SIPp завершился после одного обработанного вызова, shell prompt вернулся. Подтверждены успешный SIP-диалог и возврат RTP-пакетов механизмом эха. Пользователь затем подтвердил слышимость эха. Первый INVITE в журнале: INVITE sip:74991234567@127.0.0.1:5062 SIP/2.0. Передача точного внешнего номера и звук через локальный транк подтверждены; поле From отдельно не запрашивалось.

Проверка проводится через локальный SIP-узел, не через реальную городскую сеть. После настройки исходящего шаблона также следует повторить внутренний звонок, чтобы проверить приоритет _3XXX.
