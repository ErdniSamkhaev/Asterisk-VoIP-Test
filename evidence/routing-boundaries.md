# Внутренние и внешние маршруты

28.10.2026: после добавления общего исходящего шаблона подтверждён прямой вызов 3000→3301, звук в обе стороны. CLI dialplan show для 3000 и 3999 вывел _3XXX с Dial(PJSIP/${EXTEN},30), а также менее специфичный _X. с переходом в to-provider. Для 4000 выведен только _X. Таким образом, внутренний шаблон покрывает обе границы диапазона и имеет приоритет для внутренних номеров; 4000 находится за пределами диапазона. CLI-проверка сама звонков не создаёт. Аккаунт3999 не создавался. Ранее исходящий74991234567 подтверждён отдельным SIPp-тестом с точным Request-URI и RTP-эхом.
