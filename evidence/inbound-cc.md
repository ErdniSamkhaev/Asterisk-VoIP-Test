# Входящий основной DID и проверка заголовков КЦ

## Запуск

Пользователь выполнил sh /usr/local/sbin/test_queue_headers.sh. Скрипт использует UAC-сценарий с DID 74990000000 и временный verbose-журнал Asterisk lab-headers.log. Перед тестом подтверждён доступный контакт оператора 3300.

## Подтверждённый результат

SIPp: один вызов, Successful call 1, Failed call 0. Получены 100 и 200 INVITE, отправлен ACK, получен BYE и подтверждён 200. В показанной таблице нет таймаутов, ретрансляций и неожиданных сообщений. Пользователь подтвердил слышимость эха.

После теста скрипт вывел PJSIP Logging disabled и Removed dynamic logger channel 'lab-headers.log'. Файл для проверки остался по адресу /var/log/asterisk/lab-headers.log.

Это подтверждает тестовый диалог на основном DID и звук по наблюдению пользователя. Журнал затем подтвердил Queue(cc), ответ 3300 и одинаковые X-Lab-Trace/X-Customer-ID во входящем и исходящем INVITE. F17 для этого набора подтверждён; подробности в queue-headers.md.
